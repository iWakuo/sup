# sup

个人自用的bucket，收录一些日常使用的开源应用。

## 安装

```pwsh
scoop bucket add sup https://github.com/iWakuo/erqi
scoop install sup/OSTGUI
```

## 更新

```pwsh
scoop update
scoop update sup/OSTGUI
```

## 说明

- 本仓库为个人自用 bucket，manifest 按需维护，不保证实时跟进上游版本。
- 所有应用的版权归各自作者所有，本仓库仅提供 Scoop manifest，方便安装与更新。
- 若某个应用失效、链接变更或有更好的替代，欢迎提 Issue 反馈。
